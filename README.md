# 하트 요정의 보석 왕관

Galaxy Tab S7의 전면 카메라와 손 움직임으로 플레이하는 어린이용 웹 놀이 프로토타입입니다.

## 놀이 규칙

- 손을 반짝이는 하트 보석 위에 천천히 올립니다.
- 1초 동안 머물면 보석을 하나 얻습니다.
- 보석 3개를 모으면 공주님의 왕관이 완성됩니다.
- 제한 시간이나 실패 화면은 없습니다.

## 태블릿에서 실행하기

1. Galaxy Tab S7의 인터넷 브라우저나 Chrome에서 `https://dlgusqo123-cmd.github.io`를 엽니다.
2. `손으로 시작하기`를 누릅니다.
3. 카메라 사용 요청이 나오면 허용합니다.
4. 전면 카메라 앞에서 손을 움직여 보석을 모읍니다.

## 사용 기술

- HTML/CSS/JavaScript 단일 화면 웹 앱
- MediaPipe Hand Landmarker (`@mediapipe/tasks-vision`) 손 위치 인식
- 카메라 영상은 브라우저 안에서만 처리하며 저장하거나 업로드하지 않습니다.
